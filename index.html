How FloodGuard Works

Four simple stages from environmental monitoring to emergency notification.

01

Detect

Sensors continuously measure water level and environmental conditions.

02

Analyse

The system analyses sensor readings against predefined flood-risk thresholds.

03

Alert

When the water level becomes dangerous, the system can generate an early warning through the app.

04

Respond

Users can take preventive action and prepare for possible evacuation using the best routes.

System Features

Designed to combine monitoring, data analysis and early-warning capabilities.

🌊

Water Level Monitoring

Continuously monitor water levels using flood detection sensors.

🌧️

Rainfall Monitoring

Rainfall information can be combined with water-level data to improve risk assessment.

🚨

Early Warning

Generate warning notifications when predefined thresholds are reached.

📊
